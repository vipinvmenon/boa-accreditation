Round 6: round 4, decluttered

Round 4 kept, with the clutter taken out of the ticket: no label grid, no loud badges, no help line, a softer outline, the pass number moved into the stub. Everything else is round 4. Built to open from WhatsApp: everything fits in the WhatsApp in-app browser on an ordinary phone (390 by 762 shown, the space left under WhatsApp's own top bar), with no scrolling. The poster is now a full-cover layer, so it can never be cut off. The "Purple band / Blue band" line is gone. Sign-in is unchanged from round 3.

The pass

Order on screen: name and who they work for, tier and day, the zones they may enter, then the QR with the pass number under it. A slow light sweep crosses the ticket every few seconds (React Bits Glare Hover, adapted to run on its own): a screenshot of a pass can't do that, so a steward can tell a live pass from a copy at a glance. It stops for people who turn motion off.

React Bits: what to use, and where

React Bits components are copied into the repo as source (TypeScript + plain CSS matches this app; it has no Tailwind). Licence is MIT with Commons Clause: fine to use in the product. I checked each component's real dependency list in the React Bits registry. The app has no animation library today, so "no deps" components cost nothing extra; the ones needing motion add one library (motion for React, tens of KB gzipped) and should stay off the offline gate unless worth it.

ComponentWhereWhy it earns its placeDeps
Glare HoverPass ticketAuto-sweeping light (shown above). A static screenshot can't reproduce it, so it's a real anti-screenshot cue, not decoration.none
Hold ButtonGate: "Issue band", vehicle "Log entry"Press-and-hold to confirm. Stops accidental taps from issuing a wristband twice in a rush. The ledger is append-only, so a mistaken issue costs a void.none
Split Flap TextGate result name / pass refThe departures-board flip draws the eye to the one line that changed after a scan. Short, once per scan.none
NoiseSign-in, pass, Control RoomFilm grain over the poster. Replaces the app's current inline SVG grain with one shared component.none
Spotlight CardDesk: org and user cardsSubtle cursor-follow light on hover. Desk only (mouse); does nothing on phones.none
Count UpControl Room countsApproved / collected / pending numbers roll to their value when they change, so a change is noticed.motion
Status MarkGate green / amber / redAnimated tick or cross on the scan result. Strong feedback, but the gate already has a clear colour result.motion
Tear TicketPass, first openA tear-along-the-perforation reveal of the QR. Fits the ticket perfectly, but it's 24 KB of component and adds a step before the QR. Nice, not needed.motion
Slide Commit"Send all unsent" (ACC-160)Slide to confirm a bulk send. Right idea, but it brings the Hugeicons set and the app uses one icon family.motion + icons

Recommendation: take the five no-dependency ones now (Glare Hover, Hold Button, Split Flap Text, Noise, Spotlight Card). Decide on motion separately; if yes, Count Up first.
